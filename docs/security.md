# Security

Attack surface of the current architecture: client note, off-chain indexer and prover, SP1 guest, and on-chain settle (`CleanFundsRoot`, nullifiers, vault). Some mitigations are already in the circuit or account layer; others assume planned pieces (authority-gated root register, deposit log, relayer-optional settle).

| ID | Attack type | Technique used to solve | Attack recovery |
| --- | --- | --- | --- |
| A01 | **Stolen note secret.** Attacker learns `secret` (phishing, malware, leaked prover stdin) and can forge spends for that leaf. | Client keeps secret local; never on-chain; path/secret only in private witness. Minimize who sees stdin (local prove or trusted host). | Pause settle if mass leak suspected. Victims who still hold funds should spend/migrate notes under a new secret once safe. Vault of others stays locked by their secrets/nullifiers. |
| A02 | **Forged Merkle path.** Attacker submits siblings that do not belong to an approved tree but claims membership. | Guest recomputes root from leaf+path and requires `computed_root == expected_root`; fail closed (no journal/proof). Host negative tests cover corrupt paths. | No chain damage if prove fails. If bad proofs somehow submitted, settle rejects on proof/root. Re-fetch path from honest indexer; reprove. |
| A03 | **Prove against unregistered / tip-only root.** Tree moves while proving; or attacker picks arbitrary root. | Settle requires journal `merkle_root` to have a `CleanFundsRoot` PDA (`["clean_funds_root", root]`). Historical registered roots stay valid for in-flight proofs. | `MerkleRootNotFound` → fetch path for a still-registered root (or wait for register). Rebuild indexer if needed. Funds stay in vault until valid settle. |
| A04 | **Unauthorized `CleanFundsRoot` (fake tree whitelist).** Attacker registers root of a tree they control, then proves membership and drains vault. | Root registration must be authority-gated (`GlobalConfig.authority` / deposit pipeline only). Existence of PDA means “approved by protocol,” not “anyone created seeds.” | Pause. Revoke/stop registering attacker roots. Do not honor unknown roots. Audit authority key. Restore from deposit log; only re-register roots that match rebuilt honest tree. |
| A05 | **Compromised protocol authority.** Admin key stolen: pause abuse, malicious `vkey_hash`, fake root registration, vault authority misuse. | Single `GlobalConfig.authority`; high-value ops require that signer. Prefer hardware/multisig for authority. `pause_flag` for emergencies. | Rotate authority (planned upgrade path). Pause settle. Re-verify `vkey_hash` and root set. Multisig recovery. User funds safe if vault CPI only via settle rules. |
| A06 | **Rogue / swapped circuit (wrong vkey).** Attacker proves with a weaker guest ELF that skips membership/solvency. | On-chain verify binds proof to `GlobalConfig.vkey_hash` (circuit fingerprint). Only admin can change vkey. | Pause. Restore known-good `vkey_hash`. Invalidate proofs from rogue ELF (they fail verify). Re-deploy trusted guest; update vkey after ceremony. |
| A07 | **Invalid / malleated Groth16 proof.** Junk proof or altered proof bytes to steal without witness. | `sp1-solana` pairing verify against trusted vkey; fail → `InvalidProof`. Journal bound as public inputs. | Tx fails; no state change. Client re-packs honest proof+journal. No fund movement. |
| A08 | **Journal malleation / settle param swap.** Change amount, mint, nullifier, or root after prove so chain executes different intent. | Journal is public input to Groth16; any byte change breaks verify. Packing sends proof+journal together. | Rejected settle. Resubmit unmodified proof+journal. Vault untouched. |
| A09 | **Double-spend same note.** Replay settle or concurrent spends of one leaf. | Nullifier = Poseidon(secret, leaf, mint) in journal. Settle `init` `NullifierAccount` PDA `["nullifier", nullifier]`; second `init` fails (`NullifierAlreadyUsed`). Atomic. | First success spends; later txs fail. No double vault drain. User note is consumed; no “undo” without protocol redesign. |
| A10 | **Nullifier grind / PDA collision.** Attacker finds alternate witness colliding nullifier or PDA seeds. | Poseidon/bn254 collision resistance; seeds omit user pubkey (privacy) but bind secret+leaf+mint. PDA uniqueness tests. | Extremely unlikely crypto break → pause, migrate circuit/nullifier scheme, authority freeze. Treat as protocol incident. |
| A11 | **Solvency bypass (spend > balance).** Prove swap larger than note balance. | Guest asserts `requested_swap_amount ≤ balance` before commit; else panic, no proof. | No valid proof ⇒ no settle. User reproves with legal amount. |
| A12 | **Indexer DB corruption / wrong paths.** Sparse Merkle store returns bad siblings; users cannot prove or prove wrong root. | Indexer is cache; append-only deposit log (+ optional IPFS/Arweave snapshots) is rebuild source. Paths never trusted without guest root check + on-chain root allow list. | Rebuild tree from log/snapshot; verify tip vs last honest `CleanFundsRoot`. Resume path API. Optionally open new tree for new deposits; migrate old notes if A unrestorable. Vault funds unchanged. |
| A13 | **Indexer / backend DoS or censorship.** Path API down; users cannot fetch inclusion data. | Optional self-submit settle; multi-RPC later. Decentralized leaf log so third parties can rebuild and serve paths. Relayer optional. | Spin secondary indexer from log. Users with cached path+registered root can still prove/settle. Pause only if needed for safety, not for availability alone. |
| A14 | **Prover network censorship / liveness.** Remote Groth16 unavailable; cannot wrap proofs. | Host can `execute` locally to validate; wrap via Succinct network when up. Circuit fail-closed without proof. | Wait/retry network; alternate prover if available. No settle without proof — funds remain in vault/notes, not stolen. |
| A15 | **Witness leak via prover/host.** Host or remote prover logs `PrivateInputs` (secret, path, balance). | Prefer local prove for sensitive notes; minimize retention; no secrets in git/CI. Treat network prove as trust in prover privacy. | Rotate secrets / migrate notes if leak confirmed. Pause if systemic. On-chain state still needs valid nullifier to spend. |
| A16 | **Relayer griefing / sandwich of fee-payer path.** Relayer drops txs, front-runs public journal fields, or refuses to submit. | Relayer optional; user can self-submit as fee payer. Journal binds amount/mint/nullifier/root (and planned recipient) so relayer cannot rewrite intent without breaking proof. | User submits settle themselves. Switch relayer URL. Funds safe if settle rules hold; worst case delay. |
| A17 | **Root history eviction / prove window expiry.** Old `CleanFundsRoot` closed or ring slot overwritten; in-flight proof’s root no longer allowed. | Keep N recent roots (ring / per-root PDAs). Prove against root still registered; indexer serves matching path. | Reprove against newer registered root that still contains leaf (same leaf, updated path). If leaf only under evicted root, re-register from log or migrate note. |
| A18 | **Leaf insert without real deposit / unbacked membership.** Backend inserts leaf though vault not funded. | Deposit flow must couple token custody + leaf append + root register (planned). Off-chain insert alone must not unlock settle without vault reserves. | Pause deposits. Reconcile leaves vs vault balances. Remove/never register unbacked roots. Users only settle against honest funded state. |
| A19 | **Pause flag abuse or stuck pause.** Authority pauses forever or never pauses during incident. | `pause_flag` on `GlobalConfig` freezes settle when set; operational runbook for when to pause. Multisig authority. | Unpause after incident review. If authority lost, governance/upgrade path. While paused, vault withdrawals via settle blocked — funds not drained by attackers. |
| A20 | **Program upgrade / malicious deploy.** Attacker replaces program or uses wrong program id. | Program id pinned in `declare_id!` / `Anchor.toml`; deploy keys controlled; users verify program id. BPF verified builds (roadmap). | Users refuse bad program id. Redeploy known-good artifact; restore config PDAs if needed. Do not send to unknown program. |
| A21 | **Vault CPI / reserve desync.** Buggy settle moves wrong mint/amount or corrupts zero-copy `VaultState`. | Zero-copy layout asserts; settle uses journal amount/mint; vault PDA signs SPL transfer; clippy/tests on sizes/seeds. | Pause. Reconcile token account balances vs `reserve_*`. Patch program; authority-led correction only via reviewed upgrade. |
| A22 | **Privacy linkability (deposit ↔ spend).** Observer links leaf insert index to later settle. | Nullifier PDA seeds omit wallet; path/`leaf_index` private at prove; journal reveals nullifier+root+amount not leaf index. | Operational: delay/batch inserts, avoid unique amounts if threat model requires. No fund loss; privacy degradation only. |
| A23 | **Client malware / fake UI.** Fake site steals secret or submits hostile settle packing. | Open-source client; pin UI CIDs (uncensorable-UI track); users verify program id and journal before sign. | Rotate secrets; self-submit from known-good build. Pause if mass phishing. Vault of honest notes remains protected by secrets. |
| A24 | **Deposit log / snapshot tampering on file chain.** Attacker pins alternate leaf history. | Cross-check log against on-chain deposit txs and registered roots; multiple mirrors; signed manifests by authority. | Prefer log that matches on-chain roots. Discard divergent pins. Rebuild from Solana deposit signatures if available. |
| A25 | **Tree capacity exhaustion (depth-20 full).** No more leaf slots; DoS on new membership. | Depth-20 ≈ 1M leaves; plan deeper tree or new tree forest; circuit upgrade for new depth (new vkey). | Open tree B for new deposits; keep serving tree A for unspent notes. Migrate circuit if depth bump required. Existing notes remain spendable against A’s roots. |

E2E (all settle cases)

Terminal — main demo command

One command runs the four settle cases in order (negatives before happy, then replay).

export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
cd sdk && npm install && npm run test:e2e
  1. ==> anchor build then solana-test-validator starting (program + preloaded accounts)
  2. Unit tests pass, then vitest e2e file localnet E2E
  3. Four green checks in this order: InvalidProof → unregistered root → happy path → replay
  4. Footer: Test Files 1 passed / Tests 4 passed; validator stops / ledger torn down

Pause (emergency)

Terminal — LiteSVM (not in npm e2e)

Protocol admin pause blocks settle; unpause restores. Can’t revoke a registered root yet.

export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
anchor build --ignore-keys   # if target/deploy .so missing
cargo test -p zk_spot_shield --test test_settle_scaffold -- \
  settle_rejects_when_paused unpause_allows_settle_again --nocapture
  1. test settle_rejects_when_paused ... ok
  2. With --nocapture, failure string may include ProtocolPaused
  3. test unpause_allows_settle_again ... ok — settle succeeds after unpause
  4. Narrate: emergency switch only; registered roots stay until a future revoke path

What’s in the tx

Talk over happy-path settle (same e2e run)

Localhost; ix = proof + 104-byte journal; accounts = vault, root, nullifier, tokens. No secret. Test wallet is fee payer — relayer would pay instead.

# optional live inspect (same settle tx):
KEEP_VALIDATOR=1 npm run test:e2e
# leave that terminal running; paste the printed `solana confirm -v …` line into another shell
# Ctrl+C the e2e terminal when done. Default test:e2e tears ledger down — talk bullets instead.
  1. Cluster URL is localhost / custom (not mainnet-beta)
  2. Instruction data: large proof blob + 104-byte journal (amount/mint/nullifier/root)
  3. Account metas: global config, vault, clean-funds root, nullifier PDA, four token accounts, token + system programs
  4. No secret / Merkle path in the tx — only journal publics
  5. Fee payer = ~/.config/solana/id.json test wallet (privacy link → why relayer comes next)
